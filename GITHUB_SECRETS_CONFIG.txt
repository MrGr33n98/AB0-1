COMO ADICIONAR UM SECRET:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Clique em "New repository secret"
2. No campo "Name", cole o nome (ex: POSTGRES_USER)
3. No campo "Secret", cole o valor (ex: ab0)
4. Clique em "Add secret"
5. Repita para os outros 5 secrets
